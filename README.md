moneymanager

MoneyManager is a web-based personal finance management system built using Java, JSP and Servlets that helps users track their income, expenses, budgets and savings goals in a simple and organized way.

The application allows users to record daily financial transactions, categorize spending, monitor monthly budgets and visualize their financial progress through clear summaries. It is designed to support better personal financial decisions by providing structured insights into where money is coming from and how it is being spent.

The system focuses on:

managing income and expense records in real time

organizing transactions by categories

tracking budgets and spending limits

setting and monitoring savings goals

generating simple financial summaries for better analysis

MoneyManager follows a clean server-side architecture using Java Servlets for request handling, JSP for dynamic views and a relational database for persistent storage. It is suitable as a learning project for Java web development and demonstrates practical concepts such as MVC separation, session management, form handling and CRUD operations.

This project aims to provide a lightweight, secure and extensible foundation for building modern personal finance applications using the Java web stack.
